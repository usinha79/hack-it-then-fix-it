# Safety and responsible use

The `vulnerable/` apps in this repository contain security flaws **on purpose**, for learning.

- Run them only locally, on a machine you control. Bind to `127.0.0.1`; do not deploy them or expose them to the internet.
- All data, users, documents and credentials in these labs are fake. Never put real secrets or real personal data into a lab.
- Use these techniques only against these labs or systems you are explicitly authorised to test (for example, in-scope bug bounty targets under the program's rules).
- The point of every episode is the **fix**: use what you learn to secure the AI systems you build and run.

If you find a real vulnerability in a product while learning, report it through that vendor's security contact or bug bounty program.
